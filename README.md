# Лендинг «Новогодний корпоратив 2026» — Екатерина Биндер

Готовый статический сайт: обычные HTML/CSS, без сборки, без зависимостей (кроме Google Fonts, подключённых через `<link>`). Открывается напрямую в браузере и работает на GitHub Pages «как есть».

## Почему фото не появились на `tryinvst.github.io/binder.katya`

Проверил репозиторий `tryinvst/binder.katya` — в нём закоммичен **только `index.html`**, папки `images/` там нет вообще. Поэтому все фотографии на сайте были битыми ссылками (404) — их физически не было в репозитории, страница не «прятала» их, их там просто никогда не было.

Обновите репозиторий и на этот раз загрузите **весь этот архив целиком** — `index.html` и папку `images/` (в ней теперь 8 файлов: 7 фото лендинга + `qr-max.jpg`).

## Как выложить на GitHub Pages

1. Откройте репозиторий `tryinvst/binder.katya` на github.com.
2. Удалите/замените старый `index.html` и добавьте папку `images/` целиком — со всеми файлами внутри (перетаскиванием через веб-интерфейс GitHub, или `git add . && git commit && git push`, если работаете через git).
3. Откройте **Settings → Pages** и убедитесь, что:
   - Source: `Deploy from a branch`;
   - Branch: `main`, папка `/ (root)`.
4. Сохраните — GitHub соберёт сайт за 1–2 минуты, ссылка останется `https://tryinvst.github.io/binder.katya/`.

Если после загрузки фото страница всё равно не открывается (404 у самой страницы, не только у картинок) — значит на вкладке Settings → Pages ветка или папка указаны не так, где реально лежит `index.html` (например, выбрана несуществующая ветка `gh-pages`). Проверьте и переключите на `main` / `root`.
